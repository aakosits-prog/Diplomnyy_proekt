# Diplomnyy_proekt

# Финальный проект. Инженер по тестированию плюс

Автоматизация теста для проверки получения данных о заказе по его трек-номеру в сервисе Яндекс Самокат.

## Технологии и инструменты
* **Язык программирования:** Python 3
* **Библиотеки:** `requests`, `pytest`

## Структура проекта
* `configuration.py` — базовый URL и эндпоинты (пути) API.
* `data.py` — заголовки (headers) и тело запросов (body).
* `sender_stand_request.py` — функции для отправки POST и GET запросов.
* `test_avto.py` — позитивный автотест для проверки статус-кода ответа.
